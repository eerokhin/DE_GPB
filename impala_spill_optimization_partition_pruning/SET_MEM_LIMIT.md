## SET MEM_LIMIT в Impala

`MEM_LIMIT` — настройка, задающая максимальный объём памяти, доступный запросу на одном узле кластера.

**Установка лимита:**

```sql
SET MEM_LIMIT=10g;
```

### Зачем нужен

При выполнении тяжёлых операций, например `HASH JOIN`, Impala использует память для хранения хеш-таблиц и промежуточных данных.

Если доступной памяти недостаточно, Impala может выгружать промежуточные данные на диск. Это называется **spill** и может замедлять выполнение запроса.

Увеличение `MEM_LIMIT` позволяет использовать больше памяти и в некоторых случаях избежать spill.

### Использование в Python

Настройку можно задать перед циклом выполнения SQL-запросов:

```python
cursor.execute("SET MEM_LIMIT=10g")

for query in queries:
    cursor.execute(query)
```

Настройка действует в рамках текущей сессии Impala и распространяется на последующие запросы.

### Использование в SQL

В рамках текущей сессии Impala, перед выполнением SQL-скрипта, выполнить запрос:

```sql
SET MEM_LIMIT=10g;
```

### Как проверить необходимость увеличения лимита

В `EXPLAIN` изучают план выполнения, а в **Query Profile** — фактические показатели:

- `Memory Spilled` — объём данных, выгруженных на диск.
- `Peak Memory Usage` — пиковое потребление памяти.
- `Query Duration` — время выполнения запроса.

### Важно

- `MEM_LIMIT` задаёт ограничение, а не объём памяти, который запрос обязательно использует.
- Увеличение лимита может уменьшить spill, но не гарантирует ускорения запроса.
- Слишком высокий лимит может увеличить нагрузку на кластер при параллельном выполнении запросов.
